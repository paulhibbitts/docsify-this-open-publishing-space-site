# Open Publishing Space Guides – Converted to Docsify-This

> The two example guides from the [Grav Open Publishing Space skeleton](https://github.com/hibbitts-design/grav-skeleton-open-publishing-space), converted to plain Markdown pages for [Docsify-This](https://docsify-this.net/#/) by the [Open Publishing Guides Converter](https://open-publishing-guides-converter.hibbittsdesign.org).

View it as a website: https://docsify-this.net/?basePath=https://raw.githubusercontent.com/paulhibbitts/docsify-this-open-publishing-space-site/main&homepage=home.md&sidebar=true&loadSidebar=_sidebar.md&loadNavbar=_navbar.md&collapsibleSidebarGroups=true&pagination=true&searchbox=true&name=Open%20Publishing%20Space%20Guides

These pages are the converter's output as it is, with one addition: the site title (`- [Open Publishing Space Guides](home.md ":class=site-title")`) at the top of each `_navbar.md`, as the converter's notes suggest.

Within a guide, the sidebar lists its sections and pages, and Previous/Next buttons follow that order; the Guides page and the guide home pages have no sidebar.

The original guides are built with Grav Open Publishing Space at https://demo.hibbittsdesign.org/grav-open-publishing-quark2 – this version uses the same content:

- `home.md` – the Guides page, with a card for each guide
- `open-education-essentials/`, `sample-guide/` – one folder per guide: `README.md` (its home page, with its cover and a card for each section), a folder per section with its pages and images, `_sidebar.md` and `_navbar.md`

Each page also keeps its Grav settings in a hidden note at the top, so the converter can turn these pages back into Grav pages unchanged.
